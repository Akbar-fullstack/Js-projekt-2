# Js-projekt-2
В этом проекте я разработал веб‑страницу, где представлены четыре варианта наручных часов с уникальным и стильным дизайном.

Технологии:
HTML — структура сайта
CSS — стилизация и оформление
Tailwind CSS — современный утилитарный фреймворк для адаптивного дизайна
JavaScript — интерактивность и динамические элементы

Особенности проекта:

Четыре варианта наручных часов с разным визуальным стилем
Современный и минималистичный интерфейс
Использование Tailwind для быстрой и аккуратной верстки
Лёгкая навигация и акцент на визуальную привлекательность

Цель:  
Проект создан для демонстрации навыков в веб‑разработке и дизайне, а также для практики работы с Tailwind CSS и JavaScript при создании адаптивных и эстетичных интерфейсов.
